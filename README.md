# 📝 SmartNotes

A modern and responsive note-taking web application that helps users create, organize, search, and manage notes through a clean and user-friendly interface.

## 📌 About the Project

SmartNotes is a lightweight note-taking application built with HTML, CSS, and JavaScript.

The application provides essential note management features, including rich-text formatting, categories, color-coded notes, pinning, and sorting.

The project focuses on a clean user interface, responsive design, intuitive interactions, and an organized note-taking experience.

## ✨ Features

- 📝 Create and manage notes
- ✏️ Edit existing notes
- 🗑️ Delete unwanted notes
- 🎨 Rich-text formatting with bold, italic, and underline
- 🔎 Search notes by keywords
- 🗂️ Organize notes using categories
- 📌 Pin important notes for quick access
- 🌈 Customize notes with different colors
- ↕️ Sort notes using available sorting options
- 💾 Save notes in the browser
- 🔄 Retain saved notes after page refresh
- 📱 Responsive interface for desktop and mobile
- ✨ Interactive controls and visual feedback

## 🚀 Getting Started

1. Clone the repository:

   git clone https://github.com/Kalyansai78/SmartNotes.git

2. Navigate to the project directory:

   cd SmartNotes

3. Open `index.html` in your browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension.
